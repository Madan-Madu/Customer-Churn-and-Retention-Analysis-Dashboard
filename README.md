# Customer-Churn-and-Retention-Analysis-Dashboard
Power BI project analyzing customer churn and retention trends across 7,000+ telecom customers, providing actionable insights to improve customer retention.

📌 Overview

This Power BI dashboard analyzes telecom customer churn and retention trends for 7,043 customers, uncovering the key drivers behind customer loss and helping improve retention strategies.

🧰 Tools & Technologies

Power BI

Excel / CSV Data

DAX Measures

Data Cleaning & Transformation (Power Query)

📊 Key KPIs

Total Customers: 7,043

Churned Customers: 1,869

Overall Churn Rate: 26.5%

Yearly Charges: $16.06M

Monthly Charges: $456K

📈 Key Insights

42% of high-risk customers used fiber-optic service with month-to-month contracts.

Electronic check users showed the highest churn rate, contributing to $16M annual charges.

Long-term contracts (1–2 years) significantly reduced churn.

New customers (<1 year) were more likely to churn — onboarding improvements needed.

🧩 Business Impact

Helped identify top churn drivers and customer segments at risk.

Enabled management to design targeted retention campaigns.
